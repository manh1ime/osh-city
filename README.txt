Убраны настройки «Основной цвет» и «Валюта» из панели менеджера.

Распакуйте архив в корень проекта с заменой файлов и выполните:

npm run build

Защита сделана на двух уровнях:
1. Поля удалены из интерфейса.
2. Server action игнорирует подменённые primaryColor и currency и сохраняет текущие значения ресторана.

Миграция базы данных не требуется.
