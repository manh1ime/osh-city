# Тема «Восточная ночь» для всего приложения

Пакет меняет оформление всего сервиса, сохраняя действующую логику заказов, бронирований, QR-кодов, предзаказов, сотрудников и менеджера.

## Что изменяется

- главная гостевая страница получает оформление «Восточная ночь» и оценку 4,4;
- меню по QR-коду и меню предзаказа по бронированию получают одну темную восточную тему;
- кабинет гостя, страницы брони и заказа оформляются в той же стилистике;
- панели официанта, старшего официанта и менеджера получают общую темную палитру;
- добавляется новая ресторанная обложка;
- карточки, таблицы, формы, вкладки, модальные окна и кнопки приводятся к единому стилю;
- функциональность и схема базы не заменяются.

## Установка

Распакуйте архив с объединением папок в корень проекта, затем выполните:

```bash
node scripts/apply-eastern-night.mjs
npx tsx prisma/apply-eastern-night.ts
npx prisma generate
npm run build
```

После успешной сборки:

```bash
npm run dev
```

Скрипты идемпотентны, их можно запустить повторно. Тема подключается через `src/app/eastern-night.css`, поэтому не перезаписывает ваш текущий `globals.css` и компоненты с логикой бронирований или заказов.
