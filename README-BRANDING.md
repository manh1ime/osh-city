# Полный ребрендинг сервиса на «Учкудук»

Пакет заменяет название во всём исходном коде и в текстовых данных PostgreSQL, устанавливает канонические значения ресторана (`Учкудук`, `uchkuduk`) и задаёт единый публичный адрес для QR-ссылок.

## Применение

Из корня проекта:

1. Сначала обновите существующую базу данных:

```bash
npx prisma db execute --file "prisma/replace-branding.sql" --schema "prisma/schema.prisma"
```

2. Затем обновите исходники, конфигурацию и QR-адрес. По умолчанию используется `https://uchkuduk.ru`:

```bash
node scripts/apply-uchkuduk-branding.mjs --url=https://uchkuduk.ru
```

Если приложение опубликовано по другому адресу, укажите настоящий публичный адрес вместо `https://uchkuduk.ru`. Этот адрес записывается в `NEXT_PUBLIC_APP_URL` в `.env` и `.env.example` и используется для всех QR-ссылок столов.

3. Пересоберите приложение:

```bash
npx prisma generate
npm run build
```

4. Проверьте отсутствие прежнего названия:

```bash
rg -n -i "учкудук|uchkuduk|uchkuduk" . --glob "!node_modules/**" --glob "!.git/**" --glob "!*.zip"
```

Команда не должна ничего вывести.

## Важно про QR-коды

Токены столов не меняются, поэтому заказы и история сохраняются. Меняется базовый домен ссылок: итоговый формат — `https://uchkuduk.ru/menu/<токен-стола>`. Если QR-коды уже были распечатаны со старым доменом, их нужно сгенерировать/распечатать заново после запуска seed или штатного экспорта QR-кодов.

Скрипт применения автоматически удаляет себя после успешного запуска, чтобы в репозитории не оставалось служебных шаблонов со старым названием. SQL-файл и этот README будут обработаны тем же скриптом и также больше не будут содержать прежнее название.
