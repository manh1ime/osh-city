# Водопад

Рабочий прототип QR-меню и приема заказов для ресторана. В продукте осталось две роли: **официант** и **менеджер**. Гость открывает меню без регистрации по QR-коду стола.

## Основные сценарии

- Гость: меню, поиск, карточки блюд, корзина, комментарии, вызов официанта, отправка и статус заказа.
- Официант: новые заказы, подробности, принятие, передача на кухню, завершение, отмена и вызовы гостей.
- Менеджер: сводка, все заказы, меню, категории, стоп-лист, столы и QR-коды, сотрудники, настройки ресторана.

## Демо-доступы

| Роль     | Email             | Пароль    |
| -------- | ----------------- | --------- |
| Официант | `waiter@demo.ru`  | `demo123` |
| Менеджер | `manager@demo.ru` | `demo123` |

Маршруты:

- Гостевое меню: `/menu/[tableToken]`
- Панель официанта: `/staff/login`
- Панель менеджера: `/manager/login`

## Локальный запуск

```bash
npm install
docker compose up -d
npx prisma generate
npx prisma migrate dev
npm run db:seed
npm run dev
```

Откройте `http://localhost:3000`.

## Новые рабочие разделы

- Гость: `/menu/[tableToken]/activity` показывает заказы текущего гостевого устройства за последние 30 дней, состав и этапы, а также состояние вызова официанта.
- Менеджер: `/manager/reports` строит отчет с даты по дату и разделяет позиции кухни и бара. Категории «Напитки» и «Бар» относятся к бару, остальные к кухне.
- Официант: `/staff/summary` показывает личные завершенные заказы, оборот, средний чек и разбивку по дням.

Для текущего локального прототипа схема синхронизируется командой `npx prisma db push`. Папка старой неполной миграции удалена, чтобы она не ломала shadow database.
