# Контрастные статусы панели менеджера

Это накопительное исправление заменяет предыдущий стиль статуса «Активен» и добавляет такой же заметный статус «Отключён».

- «Активен»: светло-зелёный фон, тёмно-зелёный текст и зелёный индикатор.
- «Отключён»: светло-красный фон, тёмно-красный текст и красный индикатор.

Распакуйте архив в корень проекта и выполните:

```bash
node scripts/apply-manager-status-badges.mjs
npm run build
```

Миграция базы данных не требуется.
