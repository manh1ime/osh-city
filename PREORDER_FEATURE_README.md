# Предзаказ блюд к бронированию

## Что добавлено

- После успешной брони гость может сразу открыть электронное меню.
- Тот же переход доступен из «Моих бронирований» и со страницы конкретной брони.
- Используется тот же компонент электронного меню и тот же визуальный стиль, что у QR-меню.
- В корзине гость выбирает один из режимов:
  - `SERVE_ON_ARRIVAL` — приготовить заранее и подать сразу после посадки;
  - `PREPARE_AFTER_SEATING` — начать готовить только после отметки «Гости за столом».
- Предзаказы отображаются внутри брони у старшего официанта соответствующего филиала.
- Для режима `PREPARE_AFTER_SEATING` сервер запрещает отправку на кухню до посадки гостей.
- При отмене брони новые и подтверждённые предзаказы отменяются автоматически.

## После копирования файлов

Для production-базы PostgreSQL выполните:

```bash
npx prisma migrate deploy
npx prisma generate
npm run build
```

Для локальной разработки вместо `migrate deploy` можно использовать команду миграции, принятую в проекте.
