# Меню кафе «Ош-Сити»

Меню полностью заменено на меню «Ош-Сити». Прежних позиций в приложении нет.

## Откуда взяты позиции

Источник — папка `Меню Ош-Сити`: название папки = категория, название файла = название блюда.

| Категория | Позиций |
| --- | --- |
| Завтраки | 6 |
| Первые блюда | 8 |
| Вторые блюда | 16 |
| Мангал | 5 |
| Салаты | 10 |
| Выпечка | 1 |
| Десерты | 1 |
| Горячие напитки | 5 |
| Холодные напитки | 15 |

Всего: **9 категорий, 67 позиций**, к каждой позиции есть фотография.

## Где лежит меню

- `prisma/menu-data.ts` — категории и позиции (единственный источник меню);
- `public/menu/` — 67 фотографий блюд;
- `prisma/seed.ts` — применяет меню при `npm run db:seed`;
- `prisma/replace-menu.ts` — обновляет меню в уже работающей базе.

## Как применить

Для новой базы:

```bash
npm run db:seed
```

Для существующей базы (история заказов и предзаказов сохраняется):

```bash
npx tsx prisma/replace-menu.ts
```

Скрипт идемпотентен: повторный запуск обновляет совпадающие позиции, активирует
только актуальное меню и не удаляет историю заказов.

После заполнения нужно поправить `prisma/menu-data.ts` и ещё раз выполнить
