# Полная замена меню «Учкудук»

Пакет не заменяет `schema.prisma`, `validation.ts` и текущие файлы бронирований, поэтому ранее добавленные брони, предзаказы и ночные смены сохраняются.

## Что внутри

- 9 категорий и 70 позиций строго по согласованному списку;
- 63 предоставленные фотографии с безопасными именами;
- идемпотентный обновлятор существующей базы;
- данные нового меню для обычного `prisma db seed`;
- автоматический патч выбора вкуса «Сока Добрый».

Для 7 позиций, у которых не было подходящей фотографии, `imageUrl` оставлен пустым: салат ферганский, голубцы, суп лагман, куриные голени, куриные крылышки, соевый соус, пюре картофельное. Посторонние блюда с фотографий в меню не добавлялись.

## Установка (из корня проекта)

1. Распакуйте архив с объединением папок проекта.
2. Подключите новое меню к seed-файлу:

```bash
node scripts/apply-menu-seed-import.mjs
```

3. Добавьте выбор вкуса в текущее общее электронное меню (скрипт меняет существующий `GuestMenu.tsx`, не подменяя его старой версией):

```bash
node scripts/apply-dobry-flavors.mjs
```

4. Один раз обновите существующую базу:

```bash
npx tsx prisma/replace-menu.ts
```

5. Перезапустите приложение и проверьте меню:

```bash
npx prisma generate
npm run build
```

## Как хранится вкус

Выбранный вкус добавляется в комментарий конкретной позиции в формате `Вкус: Апельсин`. Это уже существующее snapshot-поле позиции заказа, поэтому вкус без новой миграции сохраняется и в обычном заказе, и в предзаказе по брони, и отображается гостю/официанту вместе с позицией. Разные вкусы одного сока остаются отдельными строками корзины.

Доступные вкусы: Апельсин, Вишня, Мультифрукт, Томатный, Яблочный.

## Повторный запуск

`prisma/replace-menu.ts` можно запускать повторно: он обновляет совпадающие позиции, активирует только новое меню и не удаляет исторические заказы или предзаказы.
