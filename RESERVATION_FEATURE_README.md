# Обновление бронирований

Изменённые файлы:

- `src/components/landing/LandingPage.tsx` — после успешной брони в шапке появляется кнопка «Моя бронь»; код сохраняется в `localStorage`, поэтому кнопка остаётся после обновления страницы.
- `src/app/reservation/[code]/page.tsx` — просмотр деталей брони и возможность отмены для активной будущей брони.
- `src/components/guest/ReservationCancelButton.tsx` — клиентская кнопка отмены с подтверждением, состоянием загрузки и ошибкой.
- `src/app/staff/layout.tsx` — раздел «Бронирования» для старшего официанта и менеджера.
- `src/actions/reservations.ts` — безопасная отмена только броней со статусом `PENDING` или `CONFIRMED`, обновление страниц гостя и персонала.

Существующая страница `src/app/staff/reservations/page.tsx` уже ограничивает старшего официанта его филиалом и показывает соответствующие брони, поэтому её менять не потребовалось.
