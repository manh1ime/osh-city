# Панели официанта и менеджера в стиле «Восточная ночь»

Это дополнение к общей теме приложения. Оно не заменяет компоненты и не затрагивает бизнес-логику.

## Панель официанта

- темная навигационная шапка с золотой эмблемой;
- заметный индикатор дневной или ночной смены;
- отдельные визуальные состояния новых, активных и завершенных заказов;
- улучшенные карточки заказов, вызовов и бронирований;
- золотые основные действия и спокойные второстепенные кнопки;
- адаптивная навигация для телефона и планшета.

## Панель менеджера

- единая темная рабочая область;
- восточная золотая палитра;
- переработанные таблицы сотрудников, меню, категорий и настроек;
- темные формы и модальные окна;
- улучшенные состояния строк, вкладок, ошибок и успешных операций;
- горизонтальная прокрутка больших таблиц на телефоне.

## Установка

Распакуйте архив в корень проекта с объединением папок и выполните:

```bash
node scripts/apply-eastern-night-panels.mjs
npm run build
```

После успешной сборки:

```bash
npm run dev
```

Архив содержит и базовый файл `eastern-night.css`, поэтому его можно использовать как самостоятельное накопительное обновление поверх текущего проекта.
